# 2026-VK-EDU-Web-11-Polosukhin-Y

Учебный проект «Вопросы и ответы» — AskVK. Домашнее задание №1: статическая верстка на Bootstrap 5.3.8.

## Как открыть

Откройте `public/index.html` в браузере. Установка зависимостей и подключение к интернету не нужны: Bootstrap, стили, аватары и favicon находятся в `public/static/`.

Также можно запустить локальный сервер из корня проекта:

```sh
python3 -m http.server 8000 --directory public
```

Затем откройте http://localhost:8000/.

## Страницы

| Файл в `public/` | Содержимое |
| --- | --- |
| `base.html` | Общий каркас: шапка, сайдбар и футер; комментарий на месте будущего Django-блока content |
| `index.html` | Список новых вопросов, три состояния голосования, пагинация |
| `question.html` | Вопрос, ответы, правильный ответ и форма ответа |
| `ask.html` | Форма добавления вопроса |
| `login.html` | Форма входа |
| `signup.html` | Форма регистрации |
| `profile.html` | Настройки и аватар пользователя, авторизованная шапка |

Сортировка и фильтр по тегу используют общую страницу списка: `index.html?sort=new`, `index.html?sort=popular`, `index.html?tag=python` (для каждого тега — своё значение `tag`).

На остальных страницах показана шапка гостя. Кнопка «Задать вопрос» открывает макет формы.

## Что реализовано

- Стандартные сетка, карточки, формы, кнопки и утилиты Bootstrap; собственный CSS задаёт тёмную бордовую палитру с розовым акцентом, ширину формы, перенос текста и расположение поиска на телефонах.
- Локальные SVG-аватары и favicon.
- Адаптивная сетка: на телефонах сайдбар располагается под основным контентом.
- Примеры общих ошибок формы, ошибок полей, подсказок и ограничений длины.
- Состояния «лайк», «дизлайк», «без оценки» переключаются нативными radio-кнопками; число рейтинга статическое. Нажатие на число сбрасывает выбор.
- Отмеченный и неотмеченные правильные ответы.
